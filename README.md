# Lotus-Yunzai 公告

接入宿主 Valkey 后，可沿用旧版公告的当前项、历史和编号。

| 指令 | 用途 |
| --- | --- |
| `#公告` | 查看当前公告 |
| `#历史公告 [编号]` | 查看上一条或指定的历史公告 |
| `#全部历史公告 [页码]` | 合并转发历史全文，每批十条。指定页码时只转发该页 |
| `#发布公告 <内容>` | 主人发布公告，归档原公告，并直接显示新正文 |
| `#编辑公告 <内容>` | 主人编辑当前公告，保存后直接显示正文 |
| `#撤回公告` | 主人撤回当前公告 |
| `#推送公告` | 主人向目标群推送当前公告 |
| `#公告推送回执 [编号] [页码]` | 主人查看逐群投递与撤回状态 |
| `#撤回已发公告 [编号] [群号]` | 主人按回执撤回群消息，省略编号时用当前公告 |

宿主通过 `LOTUS_VALKEY_URL` 连接旧公告所在的数据库。首次迁移可用数据库副本演练。旧记录中的 CQ 字样按原文显示。撤回的公告不会出现在历史查询中。

主人可以用 `#公告全局白名单`、`#公告全局黑名单` 管理全局目标群，或用 `#公告账号白名单`、`#公告账号黑名单` 管理单个机器人。命令后接 `添加 <群号>`、`删除 <群号>` 或 `查看 [页码]`。指定机器人时，把 QQ 放在操作前。省略机器人 QQ 时用当前连接的机器人，群聊中添加或删除时也可省略群号，表示当前群。

旧名单直接读取原 Valkey 键。群须匹配每个非空白名单，所有黑名单都生效。禁用的机器人没有目标。全局名单的添加或删除可用 `ALL`，范围是所有在线机器人当前所在的群。

主人可用 `#公告账号列表`、`#公告账号状态` 和 `#公告账号统计` 核对在线机器人和可推送群数。`#公告账号启用`、`#公告账号禁用` 批量设置在线账号。`#公告账号配置` 可查看配置，或按 `#公告账号配置 QQ 间隔 毫秒` 设置单个在线账号。也可指定 `启用/禁用` 和 `是/否`，或用 `重试 0–10` 保存旧重试配置。再次推送只补发已确认未发出的请求。

宿主提供在线机器人和群发送能力时，推送指令会按名单筛选，每个公告在同一群只选一个机器人。Valkey 记录机器人、群和已确认的消息编号。再次执行只会补发从未尝试或明确未发出的群，跳过仍在等待确认、进程中断以及结果不明的记录。当前公告被编辑或撤回后停止剩余发送，已经确认的消息保留在回执中。

`#撤回公告` 清除当前公告记录。撤回已发送的群消息时，请使用 `#撤回已发公告`。可以先用 `#公告推送回执` 查看编号，再指定某条历史公告或其中一个群。模块只向回执中的原发送机器人提交已确认消息的编号。再次执行时，只有明确未发出的撤回请求可以重试。

## 图文公告

主人可以在 `#发布公告` 或 `#编辑公告` 后附文字和图片，支持纯图片公告。图片使用 HTTPS 地址或 base64 数据，最多 5 张，总大小约 1 MiB。外部链接的有效期由来源决定。群公告、推送与历史转发保留图文顺序。Valkey 的 `content` 继续保存纯文本，附加的 `segments` 字段用于恢复图片。

## 定时推送

定时推送优先读取 `LOTUS_NOTICE_SCHEDULE_CONFIG` 指定的文件，其次读取主仓的 `config/notice.yaml`。升级时两处都未设置，可继续读取旧公告插件保留的 `config/config.yaml` 和 `config/config_default.yaml`，自定义值覆盖默认值。全新安装可以使用以下配置。

```yaml
enableSchedule: true
scheduleTime: "8:00-8:30"
```

每个北京时间日期在窗口内选一个稳定的分钟。同一日期的多个实例共用 Valkey 记录，重复启动不会产生第二次推送。错过选定分钟不补发。触发时只选择旧格式中仍标记为未推送的当前公告。开始后公告有变更时，停止后续发送。主机关停时会先停止触发，再等待已发请求记录回执。

## 米游社公告与资讯

继续读取旧 `mys.pushNews.yaml` 里的崩坏3、原神、崩坏学园2、未定事件簿、星铁和绝区零公告与资讯订阅。两种频道分别设置，按原帖编号顺序共用 `maxNum`，只推送两小时内通过标题筛选的内容，并沿用旧去重键。群管理员可用 `#星铁开启资讯推送` 或 `#星铁关闭资讯推送` 设置当前群，机器人主人可用 `#星铁推送资讯` 手动触发。其他版块使用对应的游戏名，旧写法 `崩三`、`崩坏三`、`崩二`、`崩坏二`、`崩坏学园二` 和 `未定` 也可用。

群目标、标题过滤词和条数上限每轮读配置，待发内容会在投递前核对新配置。修改 `pushTime` 后重新启动模块即可应用新时间。

原神与星铁的到期提醒继续读旧 `gsActivityPush` 和 `srActivityPush`。北京时间 10:00 起轮流向已订阅的在线群发送两天内即将结束的活动，续用当天旧队列。群管理员可发送 `#原神开启到期活动推送` 或 `#原神关闭到期活动推送`，星铁用相同写法。

机器人主人可直接发送 `#推送米游社全部`，先推进原神与星铁的到期提醒，再检查六个版块的公告与资讯订阅。只向各频道已订阅的在线群投递，沿用定时任务的过滤、条数上限与去重。口令 `#推送资讯` 仍只触发原神资讯，`#推送公告` 用于本机公告。

发送 `#原神公告`、`#星铁资讯` 或 `#绝区零公告2` 查询米游社。公告和资讯可按原顺序查询前 20 条，命令后加 `列表` 查看最近 5 条的图卡和原文链接。图卡暂不可用时仍给出可点击的列表。`#公告` 用于本机公告，`#官方公告` 查看原神官方公告。群推送和手动查询均优先展示同一份图文详情，详情暂不可用时保留摘要和原文地址。

`#原石预估`、`#星琼盘点`、`#菲林预估` 和 `#水晶预估` 查固定作者在米游社发布的公开统计帖。返回该来源检索到的第一篇，版本以原文标题为准。

米游社图文卡参照 [原公告详情模板](https://github.com/TimeRainStarSky/Yunzai-genshin/tree/0290a17cd42c52671e3130fe4a0a5aa38a64faa4/resources/html/mysNews) 的白底、作者、二维码、标题和正文次序，使用 Skia 绘制。作者头像、配图及原文从米游社公开接口读取。 正文保留原文的内联颜色、加粗和 HTTPS 链接的视觉标示。公开详情主域不可用时尝试同站的公开接口别名。 列表与公告配图也会在网络异常时尝试已核同站地址，原文链接保持米游社原入口。

原神列表可读取旧部署的 `plugins/genshin/resources/html/mysNews-list/蒙德.png` 或迁移至 `data/genshin/resources/html/mysNews-list/蒙德.png`。同游戏授权页眉也可放入 `data/notice/miyoushe/<gs|sr|zzz>/header.png`。缺图时保留原模板的素白页眉。

本模块独立实现，兼容旧 `notice-plugin` 的 Redis 键和指令。格式参考 tttfff/notice-plugin 的 MIT 版本 `92a3f53ca227a02e3b27e66e837c68c833ec6859`。
