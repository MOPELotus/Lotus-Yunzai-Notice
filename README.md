# Lotus-Yunzai 公告

接入宿主 Valkey 后，可沿用旧版公告的当前项、历史和编号。

| 指令 | 用途 |
| --- | --- |
| `#公告` | 查看当前公告 |
| `#历史公告 [编号]` | 查看上一条或指定的历史公告 |
| `#全部历史公告 [页码]` | 分页查看历史摘要 |
| `#发布公告 <内容>` | 主人发布公告，原公告归档 |
| `#编辑公告 <内容>` | 主人编辑当前公告 |
| `#撤回公告` | 主人撤回当前公告 |

宿主通过 `LOTUS_VALKEY_URL` 连接旧公告所在的数据库。首次迁移可用数据库副本演练。公告按文本回复，旧记录中的 CQ 字样保留原文。撤回的公告不会出现在历史查询中。定时推送、目标群管理和媒体段尚未接入。

本模块独立实现，兼容旧 `notice-plugin` 的 Redis 键和指令。格式参考 tttfff/notice-plugin 的 MIT 版本 `92a3f53ca227a02e3b27e66e837c68c833ec6859`。
